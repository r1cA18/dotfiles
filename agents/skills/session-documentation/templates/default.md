# Guide Template (default)

**保存先:** `docs/guides/{filename}.md`
**用途:** 再利用可能な手順書・ハウツーガイド

---

## テンプレート構造

```markdown
# {タイトル}

## 概要

{このガイドが解決する課題・目的を1-2文で}

## 背景・課題

### 元々の状態
{作業前の状態・問題点}

### 問題点
{なぜ対応が必要だったか}

## 調査内容

### 1. {調査項目1}

{調査結果の詳細}

**主なポイント:**
- ポイント1
- ポイント2

### 2. {調査項目2}

{調査結果の詳細}

## 実施手順

### 1. {手順1のタイトル}

{手順の説明}

```bash
# コマンド例があれば
```

### 2. {手順2のタイトル}

{手順の説明}

## まとめ

| 項目 | 内容 |
|------|------|
| {項目1} | {内容1} |
| {項目2} | {内容2} |

## 参考リンク

- [{リンクタイトル1}]({URL1})
- [{リンクタイトル2}]({URL2})
```

---

## ファイル名の例

- `app-icon-creation.md`
- `ci-cd-setup.md`
- `authentication-implementation.md`
