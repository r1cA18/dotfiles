# Session Log Template

**保存先:** `docs/sessions/{YYYY-MM-DD}-{title}.md`
**用途:** セッションの作業ログ・日報

---

## テンプレート構造

```markdown
# セッションログ: {YYYY-MM-DD} - {簡潔なタイトル}

## サマリー

{このセッションで達成したことを1-2文で}

## やったこと

- [x] {完了したタスク1}
- [x] {完了したタスク2}
- [ ] {未完了のタスク}

## 学んだこと

### {学び1のタイトル}
{詳細}

### {学び2のタイトル}
{詳細}

## 調査したこと

| トピック | 結果 |
|---------|------|
| {調査1} | {結果の要約} |
| {調査2} | {結果の要約} |

## 変更したファイル

- `path/to/file1.swift` - {変更内容}
- `path/to/file2.swift` - {変更内容}

## 次回への引き継ぎ

### 未完了タスク
- [ ] {タスク1}
- [ ] {タスク2}

### 注意点・メモ
- {注意点1}
- {注意点2}

## 関連リンク

- [{リンク1}]({URL1})
- [関連ドキュメント](../guides/{filename}.md)
```

---

## ファイル名の例

- `2025-01-15-icon-creation.md`
- `2025-01-14-subscription-feature.md`
- `2025-01-13-bug-fixes.md`
