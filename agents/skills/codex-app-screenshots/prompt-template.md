# App Store Screenshot Prompt Template

## Usage

固定部分はそのまま使う。`{{...}}` のプレースホルダーをプロジェクトに合わせて埋める。
最終プロンプトは「固定制約 + アプリ情報」を結合して1つのメッセージとして送信する。

---

## 固定制約 (常にそのまま使う)

Apple App Store用のスクリーンショット画像を作って。

添付画像は2種類ある：
- 参考画像：レイアウトや見せ方の参考にする画像
- 使用画像：実際にiPhoneモックアップ内へ入れるアプリ画面のスクリーンショット

【出力条件】
- 出力サイズ比率は 1284 x 2778
- 縦長のApp Storeスクリーンショット
- そのまま使える完成画像にする
- 外側に白い枠、カード枠、ポスター枠、余計なフレームは付けない
- 背景は画面いっぱいまで使う

【重要な制約】
- iPhone本体を縦に伸ばさない
- 使用画像のスクリーンショットを縦に伸ばさない
- スマホ本体と中のスクリーンショットの縦横比を正しく保つ
- 使用画像は歪ませず、自然な比率のままiPhoneモックアップ内に配置する
- 画面を無理に引き伸ばして余白を埋めない
- 必要なら縮小や配置調整で対応する
- iPhoneは自然な正面モックアップにする

【レイアウト条件】
- 上部に大きな見出しを配置
- 見出しの下に短い説明文を配置
- その下にiPhoneモックアップを大きく中央配置
- 情報を詰め込みすぎず、余白をしっかり取る

【画像の扱い】
- 参考画像は雰囲気・構図・見せ方の参考として使う
- 使用画像はiPhone画面の中に入れる主役の画面として使う
- 使用画像のUI内容はなるべく崩さず、読めるように見せる
- 参考画像そのものをそのまま複製しない

【避けること】
- 外側に角丸カードを作ること
- ポスターの中にさらに枠を作ること
- スマホやスクリーンショットの縦横比を崩すこと
- スクリーンショットを不自然に引き伸ばすこと
- UIを見えにくくすること
