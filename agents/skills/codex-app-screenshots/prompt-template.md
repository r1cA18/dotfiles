# App Store Screenshot Prompt Template

## Usage

固定部分はそのまま使う。`{{...}}` のプレースホルダーをプロジェクトに合わせて埋める。
最終プロンプトは「固定制約 + アプリ情報」を結合して1つのメッセージとして送信する。

---

## 固定制約 (デバイスに合わせてプレースホルダーを埋める)

Apple App Store用のスクリーンショット画像を作って。

添付画像は2種類ある：
- 参考画像：レイアウトや見せ方の参考にする画像
- 使用画像：実際に{{DEVICE_LABEL}}モックアップ内へ入れるアプリ画面のスクリーンショット

【出力条件】
- 出力サイズ比率は {{OUTPUT_SIZE}}
- {{ORIENTATION_JA}}のApp Storeスクリーンショット
- そのまま使える完成画像にする
- 外側に白い枠、カード枠、ポスター枠、余計なフレームは付けない
- 背景は画面いっぱいまで使う

【重要な制約】
- {{DEVICE_LABEL}}本体を縦に伸ばさない
- 使用画像のスクリーンショットを縦に伸ばさない
- デバイス本体と中のスクリーンショットの縦横比を正しく保つ
- 使用画像は歪ませず、自然な比率のまま{{DEVICE_LABEL}}モックアップ内に配置する
- 画面を無理に引き伸ばして余白を埋めない
- 必要なら縮小や配置調整で対応する
- {{DEVICE_LABEL}}は自然な正面モックアップにする

【レイアウト条件 (縦向き)】
- 上部に大きな見出しを配置
- 見出しの下に短い説明文を配置
- その下に{{DEVICE_LABEL}}モックアップを大きく中央配置
- 情報を詰め込みすぎず、余白をしっかり取る

【レイアウト条件 (横向き)】
- 左側に見出しと説明文、右側に{{DEVICE_LABEL}}モックアップを配置
- または上部に見出し、下部に横向き{{DEVICE_LABEL}}モックアップを中央配置
- 横長レイアウトを活かしたバランスの良い構図にする

【配色】
- アプリの実際の配色（メインカラー、アクセントカラー）を背景やテキストに反映する
- アプリのデザインと調和した色合いにする

【画像の扱い】
- 参考画像は雰囲気・構図・見せ方の参考として使う
- 使用画像は{{DEVICE_LABEL}}画面の中に入れる主役の画面として使う
- 使用画像のUI内容はなるべく崩さず、読めるように見せる
- 参考画像そのものをそのまま複製しない

【避けること】
- 外側に角丸カードを作ること
- ポスターの中にさらに枠を作ること
- デバイスやスクリーンショットの縦横比を崩すこと
- スクリーンショットを不自然に引き伸ばすこと
- UIを見えにくくすること

### プレースホルダーの値

| プレースホルダー | iPhone 縦 | iPhone 横 | iPad 縦 | iPad 横 |
|------------------|-----------|-----------|---------|---------|
| `{{DEVICE_LABEL}}` | iPhone | iPhone | iPad | iPad |
| `{{OUTPUT_SIZE}}` | 1284 x 2778 | 2778 x 1284 | 2048 x 2732 | 2732 x 2048 |
| `{{ORIENTATION_JA}}` | 縦長 | 横長 | 縦長 | 横長 |
